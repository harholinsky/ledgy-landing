Connect Ledgy to ChatGPT

About a minute
  1. 1
    Connect Ledgy to ChatGPT

    The button opens the Ledgy app inside ChatGPT.

    Connect Ledgy to ChatGPT

  2. 2
    Follow the instructions

    Click Connect, sign in with Apple, Google, or email, and grant access.

  3. That's it — just chat

    Mention Ledgy or ask about your money in any chat — “What did I spend on groceries in July?” ChatGPT picks the app up automatically.

App not available on your plan or region, or prefer manual setup?

Turn on Settings → Apps → Advanced settings → Developer mode (needs ChatGPT Plus, Pro, or Business), click Create, and fill in:

  • Name: Ledgy
  • MCP Server URL: https://api.ledgy.app/mcp
  • Authentication: OAuth

Full statement-import walkthrough on the Ledgy in ChatGPT page.

Connect Ledgy to Claude

About a minute
  1. 1
    Open connector settings

    In claude.ai or Claude Desktop, go to Settings → Connectors → Add custom connector.

  2. 2
    Paste the Ledgy server URL

    Name: Ledgy. Server URL:

    https://api.ledgy.app/mcp
  3. 3
    Add and sign in

    Click Add, sign in with Apple, Google, or email, then enable Ledgy from the connectors menu in any chat.

  4. That's it — just ask

    “How does my April spending compare to March?” Claude answers from your own data.

You can also drop a bank statement into Claude and have it imported — see the walkthrough; the same workflow works in Claude.

Connect Ledgy to Cursor

About a minute
  1. 1
    Add Ledgy to Cursor

    One click — the button opens Cursor with the Ledgy MCP server pre-filled.

    Add Ledgy to Cursor

  2. 2
    Follow the instructions

    Click Install when Cursor opens, then finish the sign-in in your browser.

  3. That's it — ask the agent

    “Log the €14 team lunch I just paid for.” Works in chat and in the composer.

Prefer to add it by hand?

Add this to your mcp.json (Cursor Settings → MCP), then complete the OAuth sign-in when prompted:

mcp.json
{
  "mcpServers": {
    "ledgy": { "url": "https://api.ledgy.app/mcp" }
  }
}

Expenses logged from Cursor sync instantly to the web dashboard and the iOS app.

Connect any MCP client

About a minute
  1. 1
    Add a remote MCP server

    In Windsurf, VS Code, Continue, Zed, or your own agent, add a remote server and point it at:

    https://api.ledgy.app/mcp
  2. 2
    Sign in when prompted

    Your client completes OAuth 2.1 with PKCE. Dynamic Client Registration (RFC 7591) is supported, so no manual client_id or credential exchange is needed.

  3. That's it — same tools everywhere

    Every MCP client gets the same 30+ tools across transactions, accounts, budgets, and more.

Trust

Privacy & control

Sees only what you ask about

The assistant gets the data your question needs. We don't push your full ledger to Anthropic or OpenAI on connection.

Your password stays yours

You sign in on Ledgy's own consent page with Apple, Google, or email. The assistant never sees your password.

Disconnect any time

Remove the connector in your client's settings — Claude, ChatGPT, or any other. Revoking access takes effect immediately.
